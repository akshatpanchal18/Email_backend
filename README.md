# Express TypeScript Backend

A backend API built with **Express.js**, **TypeScript**, **Prisma**, and **PostgreSQL**.

## Tech Stack

- Node.js
- Express.js
- TypeScript
- Prisma ORM
- PostgreSQL
- Nodemon / tsx
